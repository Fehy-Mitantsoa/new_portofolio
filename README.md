## 🎬 Démo Vidéo Cinématique 16:9

Le portfolio intègre un lecteur cinématique haute performance qui présente l'ensemble du profil sous la forme d'un showreel interactif :

| Raccourci | Action |
|---|---|
| <kbd>Espace</kbd> | Lecture / Pause |
| <kbd>→</kbd> / <kbd>←</kbd> | Chapitre suivant / précédent |
| <kbd>M</kbd> | Activer / Désactiver les effets sonores |
| <kbd>F</kbd> | Mode Plein Écran (Ratio 16:9 cinéma) |
| <kbd>Échap</kbd> | Fermer le lecteur |

## 🚀 Installation & Démarrage Local

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure recommandée)
- [npm](https://www.npmjs.com/) ou [bun](https://bun.sh/)

### 1. Cloner ou télécharger le dépôt
```bash
git clone https://github.com/votre-compte/portfolio-fenomirindra.git
cd portfolio-fenomirindra
```

### 2. Installer les dépendances
```bash
npm install
```

### 3. Lancer le serveur de développement
```bash
npm run dev
```
L'application sera accessible sur `http://localhost:3000`.

### 4. Compiler pour la production
```bash
npm run build
```
Les fichiers statiques optimisés seront générés dans le dossier `dist/`.

## 📦 Scripts Disponibles

| Commande | Description |
|---|---|
| `npm run dev` | Démarre le serveur local de développement Vite sur le port 3000 |

| `npm run preview` | Prévisualise localement le build de production |
| `npm run lint` | Exécute la vérification statique des types TypeScript (`tsc --noEmit`) |
| `npm run clean` | Nettoie les répertoires de compilation temporaires |
